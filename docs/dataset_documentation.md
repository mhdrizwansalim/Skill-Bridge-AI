
# SkillBridge by Zequa
## Dataset Documentation

### 1. Job Roles Dataset
File: job_roles.csv

Purpose:
Stores job roles across multiple industries.

Columns:
- role: Job title
- industry: Industry associated with the role
- level: Experience level
- required_skills: Skills required for the role

### 2. Skills Taxonomy Dataset
File: skills_taxonomy.csv

Purpose:
Stores skills and their corresponding categories.

Columns:
- skill: Skill name
- category: Skill category

### 3. Job Skill Mapping Dataset
File: job_skill_mapping.csv

Purpose:
Connects individual job roles with their required skills.

### 4. Industry Skill Matrix
File: industry_skill_matrix.csv

Purpose:
Compares skill requirements across industries.

### 5. Role Skill Coverage
File: role_skill_coverage.csv

Purpose:
Measures how many job-role skills are mapped to the skill taxonomy.

### Dataset Limitations
- The initial 40 job roles are a starter dataset.
- It does not represent every occupation worldwide.
- Skill coverage depends on the current taxonomy.
- Global occupation datasets such as ESCO and O*NET
  will be integrated in a later stage.
